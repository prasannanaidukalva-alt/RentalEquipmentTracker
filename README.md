# RentalEquipmentTracker
Rental companies often face difficulties in keeping track of their equipment inventory, customer rentals, and returns. Manual tracking through registers or spreadsheets can lead to confusion, data loss, and human errors.
There is a need for a computerized system that can efficiently manage rental equipment, record transactions, and maintain accurate data about each item’s availability and usage.
The System Rental Tracker is a Java-based console application developed to manage the rental operations of an equipment rental business. It allows the business to store details of available equipment, record customer rentals, and update returns with minimal manual effort.
The system provides an interactive menu through which users can:
1.	Display all equipment details (including quantity, rent per day, and usage count).
2.	Add new equipment to the inventory.
3.	Rent out equipment to customers and automatically update stock and usage count.
4.	Return equipment and restore its availability.
5.	Exit the system safely
